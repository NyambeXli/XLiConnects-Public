# XLiConnect

XLiConnect is a modern full-stack web application built for peer-to-peer communication, user status updates, and interactive messaging. 

## 🚀 Tech Stack & Technologies Used

* **Programming Language:** C#
* **Framework:** ASP.NET Core MVC (.NET)
* **Authentication & Security:** ASP.NET Core Identity
* **Database & ORM:** SQL Server, Entity Framework Core (EF Core)
* **Frontend:** HTML5, CSS3, JavaScript, Razor Views, Bootstrap

## ✨ Key Features

* **User Authentication:** Secure registration, login, and profile management (with profile picture support).
* **Status Updates:** Users can share photo-based status updates, view statuses posted by other users, and interact with them.
* **Real-Time Messaging:** Direct chat functionality between users, featuring unread message counts, live conversation loading, and precise UTC timestamps converted locally.
* **Responsive UI:** Clean, custom-styled dashboard layouts separating personal and peer activity sections.
